1. ภาพรวมงานแต่ละส่วน

ดึงข้อมูลการจราจรของกรุงเทพฯ จาก 3 แหล่งที่ไม่ต้องใช้ API key ทุก 15 นาที รวมเป็นชุดข้อมูลเดียวด้วย Airflow DAG เก็บใน PostgreSQL และแสดงผลบนเว็บ Streamlit ที่อ่านจาก PostgreSQL โดยตรง ทุกแหล่งถูกแปลงเป็น schema เดียวกันในตาราง traffic_record (source, source_id, record_type, category, title, area, period, event_time, lat, lon, congestion_pct, speed_kmh, severity, dedup_key)

แหล่งวิธีดึงข้อมูลที่ได้
TomTom Traffic IndexWeb scraping ด้วย requests อ่านข้อมูลที่ฝังใน HTML (ไม่ใช้ Selenium)ระดับรถติด (%) ของกรุงเทพฯ รายชั่วโมงทั้งสัปดาห์ 168 ค่า, รายเดือน 12 ค่า, ช่วงเร่งด่วน
Longdo TrafficJSON feed (ทำตาม Crawl-delay 10 วินาที)เหตุการณ์จราจร เช่น น้ำท่วม อุบัติเหตุ (กรองเฉพาะกรุงเทพฯ)
Traffy FonduePublic APIเรื่องร้องเรียนด้านถนน จราจร น้ำท่วม ของ กทม.

ทุกแหล่งตรวจ robots.txt ก่อนดึง และไม่เก็บข้อมูลส่วนบุคคล (ตัดชื่อผู้รายงาน ข้อความร้องเรียน และรูปภาพทิ้ง ตาม PDPA)

ระดับสิ่งที่ทำได้ผล
1 ขั้นต่ำDAG extract → transform → load → PostgreSQL → เว็บแสดงตารางและกราฟครบ
2 มาตรฐาน3 แหล่งรันขนานใน TaskGroup extract, schema เดียวกัน, UPSERT ON CONFLICT (source, source_id) (Clear แล้วรันซ้ำ log ขึ้น "ใหม่ 0"), เว็บมี KPI 5 ตัว และตัวกรอง (แหล่ง, ช่วงวัน, ประเภท, คำค้น)ครบ
3 ท้าทายแหล่งล่ม → task failed แต่ transform ใช้ trigger_rule="all_done" จึงรวมจากแหล่งที่เหลือได้ (สถานะ PARTIAL); ตัดรายการซ้ำข้ามแหล่ง: เหตุการณ์จาก Longdo และ Traffy ที่อยู่กลุ่มเดียวกัน วันเดียวกัน ห่างกันไม่เกิน ~300 ม. รวมเหลือ 1 แถวในตาราง traffic_event; ตรวจคุณภาพ (ค่าว่าง, ช่วงค่า, พิกัดต้องอยู่ในกรุงเทพฯ, เวลาไม่อยู่ในอนาคต) แล้ว @task.branch ไป load หรือ quarantineครบ
โบนัสหน้า "Pipeline Status" บนเว็บ: สถานะแต่ละแหล่ง ประวัติการรัน และแถวที่ไม่ผ่านการตรวจครบ

2. ปัญหาที่พบและวิธีแก้

ปัญหา 1: แหล่งข้อมูลที่วางแผนไว้ (Waze Live Map) ดึงไม่ได้ และ robots.txt ไม่อนุญาต

อาการ: task extract.waze ล้มเหลว ได้ HTTP 403 Forbidden

วิธีหาสาเหตุ: เขียนสคริปต์ PowerShell ทดสอบทุก URL ที่วางแผนไว้ พร้อมอ่าน robots.txt ของแต่ละเว็บ พบว่า Waze มี Disallow: /live-map/api จึงใช้ไม่ได้ตามข้อกำหนด ส่วน TomTom/HERE API ต้องใช้ key ซึ่งอาจารย์ที่รันจาก repo จะไม่มี

วิธีแก้: ทดสอบหาแหล่งที่ไม่ต้องใช้ key และ robots.txt อนุญาต ได้ TomTom Traffic Index (scrape จาก HTML), Longdo event feed และ Traffy Fondue API จากนั้นเขียนตัวดึงใหม่โดยใช้ตัวอย่างข้อมูลจริงจากการทดสอบมาเขียน unit test

ปัญหา 2: Docker Desktop เปิดไม่ขึ้น ค้างที่ "Starting the Docker Engine..."

อาการ: สั่ง docker compose up แล้วขึ้น Docker Desktop is unable to start

วิธีหาสาเหตุ: สั่ง wsl -l -v เพื่อดูว่า WSL 2 ทำงานได้ และเช็ก Virtualization ใน Task Manager [ระบุผลที่เจอ]

วิธีแก้: wsl --update, wsl --shutdown แล้ว[ระบุวิธีที่ใช้ได้จริง เช่น อัปเดต Docker Desktop / Reset to factory defaults / รีสตาร์ตเครื่อง]

ปัญหา 3: แผนที่บน dashboard ขึ้นข้อความ "Error fetching Streamlit Mapbox token"

อาการ: ส่วนอื่นของหน้าเว็บแสดงได้ปกติ แต่แผนที่ st.pydeck_chart ไม่ขึ้น

วิธีหาสาเหตุ: จากข้อความ error พบว่า pydeck ใน Streamlit ต้องดึง Mapbox token ก่อนวาดแผนที่

วิธีแก้: เปลี่ยนไปใช้ plotly.express.scatter_mapbox กับสไตล์ carto-positron ซึ่งไม่ต้องใช้ token
